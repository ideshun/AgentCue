AgentCue v0.2.0 更新界面与语音体验，保留已有工具接入和本机数据。

### 本次更新

- 统一浅色与深色界面、页面布局、表单和列表密度；操作文案更加直白。
- 办公室沿用现有插画，消息气泡、浮窗与其他页面保持一致，并显示工具最新可见任务事件的时间。
- 播报音量可在设置中按 5% 调节，保存后同时用于试听和自动播报；0% 为静音。
- 播报 `@` 文件或目录引用时只读名称。例如 `改造 @project/packages/biz-components 的组件` 播为 `改造 biz-components 的组件`。看板和系统通知中的原始标题保持不变。
- 含路径引用的新任务另生成最多 60 字的去路径播报摘要，以保留路径后的任务说明；更新前已经采集的截断标题可能仍不完整。
- 补充可版本管理的项目记忆维护说明与共享 AI 工程规则，保留已有 Cursor 配置。

### 安装与兼容

升级前完全退出旧版，再替换应用。沿用原来的 `AI Workflow Monitor` 数据目录，不需要删除设置、历史记录或模型。同一安装路径下的 Hooks / MCP 配置通常可以继续使用；从开发版迁移或改变应用路径时，从「播报接入」更新原条目。

提供 macOS Apple 芯片、macOS Intel、Windows x64 和 Linux x64 安装包；校验值见 Release 附件 `SHA256SUMS.txt`。本地 Kokoro / ZipVoice 模型仍需在应用内主动下载，不随安装包分发。

本版仍使用 Electron；Rust 重构另行推进，不包含在 v0.2.0 中。尚无正式代码签名、macOS 公证或自动更新，Windows Hooks 自动生成也尚未就绪。包内自检覆盖 SQLite、TTS 运行库、MCP 桥接、语言资源与插画；完整跨平台交互和真实音频设备需另行人工验收。
