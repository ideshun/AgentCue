AgentCue v0.1.2 是首个正式版，任务监控、语音与接入功能和 v0.1.1 预览版相同。

### 版本内容

- 保留 v0.1.1 的安装包优化：Electron / Chromium 只打包英语、简体中文与繁体中文语言资源。
- 四个平台的安装包均通过包内自检，覆盖语言资源、SQLite、TTS 运行库、当前插画、许可证和 6 个 MCP 工具。
- 所有办公室插画原稿、历史版本与设计素材继续保留在仓库；只把当前使用的插画放入应用包。

### 体积参考

同一台 Apple 芯片 Mac 重复构建测得：完整 `.app` 从约 336 MiB 降至 291 MiB，DMG 从 128.2 MiB 降至 119.0 MiB。GitHub Release 中 Apple 芯片 DMG 约 119.7 MiB。CI 也会在 macOS Intel、Windows x64 和 Linux x64 原生 runner 构建并自检。

Kokoro / ZipVoice 模型需在应用内主动下载，模型不随安装包分发。语音推理运行库继续随安装包分发。

### 安装与已知限制

Linux x64 AppImage 文件名为 `linux-x86_64`。已有用户升级前先完全退出旧版，原有数据目录 `AI Workflow Monitor` 继续使用；更新安装路径后需在「播报接入」更新原 Hooks / MCP 启动路径。

本正式版尚未配置正式代码签名和 macOS 公证，因此 macOS 可能提示开发者未验证。Windows 的 Hooks 自动生成命令尚未就绪；其余平台经 CI 打包和自检，但完整系统交互与真实音频设备未全部人工验收。当前不支持自动更新。

安装、迁移与接入说明见[README](../../README.md)和[发版手册](../releasing.md)。
