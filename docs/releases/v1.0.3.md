AgentCue 1.0.3 adds more AI tools, custom tool icons, and a cleaner desktop interface.

- Add task-event integration for DeepSeek Harness, OpenCode 2, Gemini CLI, and Qwen Code, with bundled official tool icons and setup instructions.
- Add MCP configuration templates for all four tools, including OpenCode 2 JSON and DeepSeek Harness YAML. Templates use the installed AgentCue executable path.
- Custom tools support an icon path, image selection, drag-and-drop path filling, preview, editing, and clearing. PNG, JPEG, and WebP files remain on your computer.
- Show office workstations only for tools detected as installed or running. Integration links open the matching tool and expand its setup section.
- Refine custom-tool forms, button proportions, card spacing, and notification rows. Align notification metadata and place “Mark as read” before “View” at the right edge.

DeepSeek Harness does not yet infer confirmation requests. OpenCode integration targets version 2. CLI hook availability depends on the tool version. MCP connection alone does not produce task events. Configuration parsing, synthetic protocol tests, bridge self-tests, and macOS interface checks passed; connections in every real client and manual behavior on other platforms have not all been verified.

AgentCue 1.0.3 新增更多 AI 工具接入、自定义工具图标，并调整桌面界面布局。

- 新增 DeepSeek Harness、OpenCode 2、Gemini CLI 和 Qwen Code 的任务事件接入，提供官方工具图标和配置指引。
- 为这四个工具补齐 MCP 配置模板，包含 OpenCode 2 JSON 和 DeepSeek Harness YAML，自动使用当前 AgentCue 安装路径。
- 自定义工具支持图标路径、选择图片、拖入自动填充路径、预览、编辑和清除。支持 PNG、JPEG、WebP，文件保留在本机。
- 办公室仅为检测到已安装或运行中的工具显示工位；接入链接定位到对应工具并展开配置。
- 调整自定义工具表单、按钮比例、卡片留白和通知列表；通知状态信息水平对齐，右侧按“标为已读”“查看”排列。

DeepSeek Harness 暂不推断等待确认；OpenCode 接入面向 2.x；CLI Hooks 能力取决于工具版本。MCP 连通本身不会产生任务事件。配置解析、合成协议测试、桥接自检和 macOS 界面检查已通过；尚未完成所有真实客户端连接及其他平台的人工交互验收。
