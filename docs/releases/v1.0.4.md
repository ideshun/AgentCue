AgentCue 1.0.4 improves notification pagination, history cleanup, SSE resync, and desktop UI interactions.

- Filter notifications by level before paging (`/api/v1/notifications/page`), support level-scoped “Mark all as read”, and preserve stable cursor pagination across refreshes.
- Emit `stream.resync` when the SSE event stream lags instead of `settings.changed`, and only record API audit logs for mutating (`POST`/`PUT`/`DELETE`) requests.
- Clean up expired `audit_log` entries during history cleanup and refine incremental file capture size/timestamp checks.
- Refine desktop navigation labels, board tool/date filter linking, custom tool form validation, and notification list layout.

L1 checks (`typecheck`, `test`, `lint`) and Rust workspace checks (`cargo fmt --check`, `cargo clippy`, `cargo test`) passed. Cross-platform installer builds and smoke self-tests run in the release workflow.

AgentCue 1.0.4 改进通知分页、历史清理、SSE 事件流恢复及桌面端交互细节。

- 通知接口（`/api/v1/notifications/page`）改为先按级别筛选再分页，支持按级别“全部标为已读”，并在刷新时保持稳定的游标翻页窗口。
- SSE 事件流滞后时发送 `stream.resync` 替代 `settings.changed`，并仅对写入类请求（`POST`/`PUT`/`DELETE`）记录 API 审计日志。
- 历史清理同步清理过期 `audit_log` 记录，同时修正文件增量采集的大小与修改时间校验逻辑。
- 优化桌面端导航文案、任务看板与工具/日期筛选联动、自定义工具表单校验及通知列表排版。

L1 验证（`typecheck`、`test`、`lint`）与 Rust 工作区检查（`cargo fmt --check`、`cargo clippy`、`cargo test`）已通过；跨平台安装包构建与自检将在 Release 流水线中执行。
