AgentCue v0.1.1 是一次安装包体积优化预览版，任务监控、语音和接入功能与 v0.1.0 相同。

### 变更

- Electron / Chromium 安装包只保留英语、简体中文和繁体中文语言资源，省去其他语言包。
- 每个平台的打包自检会检查语言资源、SQLite、TTS 运行库、插画、许可与 6 个 MCP 工具。
- 所有办公室插画原稿、历史版本和设计素材仍留在仓库，仅当前使用的插画进入应用包。

### 体积参考

在同一台 Apple 芯片 Mac 上重复构建测得：完整 `.app` 从约 336 MiB 降至 291 MiB，DMG 从 128.2 MiB 降至 119.0 MiB。CI 仍会分别在 macOS arm64 / x64、Windows x64 与 Linux x64 原生 runner 构建并自检。

Linux x64 的 AppImage 文件名使用 `linux-x86_64`；安装包按 CPU 架构选择即可。

Kokoro / ZipVoice 模型仍需在应用内主动下载，语音推理运行库继续随安装包分发。模型不会随包下载。

安装、数据迁移与 Hooks / MCP 说明见仓库 [README](../../README.md) 和[发版手册](../releasing.md)。

本预览版未进行正式代码签名或 macOS 公证。自动更新、Windows 自动生成 Hooks、完整跨平台交互与真实音频设备验收仍有边界，详见 README。
