# AgentCue v1.0.0

AgentCue 1.0 is the first stable release of the Rust + Tauri desktop application.

### 本版内容

- Rust 负责任务采集、状态、存储、通知、语音调度和 MCP；Tauri 2 使用系统 WebView，原 TypeScript / CSS 界面与办公室插画继续复用。
- 沿用历史数据目录、SQLite 迁移、Hooks / MCP 参数及 MCP Server 标识。升级时保留本机任务、设置和已下载模型。
- 任务看板与办公室继续展示任务状态；重要播报区分工具名称和任务标题，云语音默认关闭。
- MiMo 播报保留英文工具名，并按英文技术读法提示常见工具、Git 命令、协议和缩写；无标题任务不再朗读会话哈希。
- 发布 macOS Apple 芯片 / Intel、Windows x64、Linux x64 安装包，附件包含 SHA-256 校验清单。

### 安装与升级

完全退出旧版后安装。应用继续使用 `AI Workflow Monitor` 数据目录；不要删除该目录。若继续安装到 `/Applications/AgentCue.app`，原有 Hooks / MCP 路径和参数保持兼容。移动应用或从开发版迁移时，在「播报接入」重新复制对应配置。

Kokoro / ZipVoice 模型需要在应用中主动下载。云 TTS 需自行选择并启用，播报文本会发送至配置的服务商。

### 已知边界

- 尚未配置 Developer ID 正式签名、macOS 公证或自动更新；macOS 首次打开可能显示系统安全提示。
- Windows Hooks 自动生成尚未就绪；可用接入能力以应用内各工具的状态说明为准。
- CI 覆盖四种平台 / 架构的构建与包内自检；完整系统交互、实际工具 Hook 和音频设备仍需按目标环境验收。
