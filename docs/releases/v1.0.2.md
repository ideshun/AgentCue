AgentCue 1.0.2 improves window dragging, office status messages, and task browsing.

- Drag the page header, app branding, or empty title-bar area to move the window. Buttons and form controls remain interactive.
- Office messages sit above employees without covering their heads and can extend beyond the office container. Clicking a message opens task details directly. Working, idle, and attention states use consistent labels; details show up to five tasks with accurate counts.
- Attention messages follow unread notifications for the current task event. Marking notifications as read hides automatic attention messages, while a new confirmation event can show them again. Successful speech also records confirmations without sending a duplicate desktop alert.
- Employee status uses complete unread counts rather than a limited preview. New indexes keep office queries responsive with large task histories.
- Refine tool-source columns, settings copy, form borders, office spacing, and task-detail buttons.
- Local macOS builds use ad-hoc signing when no signing identity is supplied, and verify the completed app bundle. Developer ID signing and notarization still require configured credentials.

Kokoro and ZipVoice models remain optional downloads. Windows, Linux, Intel Mac behavior, and real audio output require checks on their target systems.

AgentCue 1.0.2 改进窗口拖动、办公室状态消息和任务浏览体验。

- 可拖动页面标题区、应用名称区和标题栏空白处移动窗口，按钮和表单控件保持正常交互。
- 办公室消息显示在员工头部上方，可超出办公室容器；点击消息可直接打开任务详情。统一工作中、空闲和需确认状态；详情最多显示五条任务，数量与列表一致。
- 需确认消息关联当前任务事件的未读通知。通知标记已读后不再自动展示，新的确认事件可再次提醒。等待确认播报成功后也会保存通知记录，不重复发送系统通知。
- 员工状态使用完整未读统计，不受预览条数限制。新增索引，改善大量历史任务下的办公室查询性能。
- 调整任务来源列、设置文案、表单边框、办公室间距和任务详情按钮。
- 本机 macOS 构建未指定签名身份时使用临时签名，并验证完整应用包。Developer ID 签名与公证仍需配置相应凭据。

Kokoro 和 ZipVoice 模型仍为可选下载。Windows、Linux、Intel Mac 的交互及真实音频输出需要在目标系统上检查。
