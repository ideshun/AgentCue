AgentCue 首次预览版：一个本地优先的 AI 编码任务监控与语音提醒桌面应用。

### 本版内容

- 将 CodeX、Claude Code、Cursor、Cline 和 CodeBuddy 的任务集中查看。
- 任务看板、时间线、动画办公室，以及按规则触发的开始／待确认／完成提醒。
- 系统音色、本地 Kokoro / ZipVoice、需主动开启的云语音。
- 按工具组织的 Hooks 与 MCP 接入说明；桥接随应用分发。
- 体积优化：只保留一份本地 TTS 运行库，排除编译中间文件和未使用的插画版本。

### 安装与更新

选择 `mac-arm64`（Apple 芯片）、`mac-x64`（Intel）、`win-x64` 或 `linux-x64` 安装包。
使用 `SHA256SUMS.txt` 校验下载文件。模型不随包分发，需要在设置中主动下载。

本版未进行正式代码签名和 macOS 公证，可能触发系统开发者验证提示。macOS 使用临时签名。
重点人工验收平台为 macOS；CI 自检覆盖打包依赖、内存 SQLite、TTS 运行库和 MCP 枚举，不替代系统交互与音频设备验收。Windows 的自动生成 Hooks 命令目前未就绪。

已有用户先完全退出旧版再替换。原有数据目录 `AI Workflow Monitor` 继续使用。
从旧名称或开发目录迁移后，在「播报接入」更新原 Hooks / MCP 配置的启动路径一次。
当前不支持自动更新。

完整说明见仓库 README、`CHANGELOG.md`、`docs/releasing.md` 和 `THIRD_PARTY_NOTICES.md`。
