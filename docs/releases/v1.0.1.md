# AgentCue v1.0.1

AgentCue 1.0.1 improves local maintenance, voice controls, task browsing, and release verification for the Rust + Tauri desktop application.

## Highlights

- Back up and restore local task data, inspect local storage usage, clean up eligible old terminal tasks, and preview a redacted diagnostics report before export.
- Manage login launch and close-to-tray behavior from the app. Update checks remain manual; the app does not auto-download or install updates.
- Inspect, import, validate, download, and remove local speech models. See the current announcement, stop playback, and retry failed announcements manually.
- Improve task filters, sorting, office preferences, onboarding, settings layout, and native form interactions.
- Add runtime maintenance and Windows Hooks coverage, with expanded Rust and desktop regression checks in CI.
- Harden release signing setup and cleanup. Signing and notarization still require repository certificates and secrets.

## Installers

Installers for macOS Apple silicon and Intel, Windows x64, and Linux x64 are attached to this release. Verify downloads with `SHA256SUMS.txt`.

Kokoro and ZipVoice model files are downloaded only when requested in the app and are not included in installers. Cross-platform UI behavior and real audio output should be checked on the target system.
