AgentCue 1.0.1 改进了 Rust + Tauri 桌面应用的本机管理、语音控制和任务浏览体验。

AgentCue 1.0.1 improves local maintenance, voice controls, and task browsing in the Rust + Tauri desktop app.

- 支持备份和恢复本机任务数据、查看存储占用、清理符合条件的旧终态任务，并在导出前预览脱敏诊断报告。
  Back up and restore local task data, inspect storage usage, clean up eligible old terminal tasks, and preview a redacted diagnostics report before export.
- 可在应用内设置登录启动和关闭窗口后的行为。更新检查仍由用户手动发起；应用不会自动下载或安装更新。
  Configure login launch and close-window behavior in the app. Update checks remain manual; the app does not automatically download or install updates.
- 可检查、导入、校验、下载和删除本地语音模型；可查看当前播报、停止播放，或手动重试失败的播报。
  Inspect, import, validate, download, and remove local speech models. View the current announcement, stop playback, or manually retry a failed announcement.
- 改进任务筛选与排序、办公室偏好、首次使用引导、设置布局和原生表单交互。
  Improve task filters and sorting, office preferences, onboarding, settings layout, and native form interactions.
- 增加运行时维护和 Windows Hooks 覆盖，并扩展 Rust 与桌面端回归检查。
  Add runtime maintenance and Windows Hooks coverage, with expanded Rust and desktop regression checks.
- 改进发版签名配置和清理流程。代码签名与公证需要在仓库配置相应证书和凭据。
  Improve release signing setup and cleanup. Code signing and notarization require certificates and credentials configured in the repository.

本版本提供 macOS Apple 芯片版与 Intel 版、Windows x64 版和 Linux x64 版。下载后可使用附件 `SHA256SUMS.txt` 校验文件。

This release includes installers for macOS Apple silicon and Intel, Windows x64, and Linux x64. Verify downloaded files with the attached `SHA256SUMS.txt`.

Kokoro 和 ZipVoice 模型需在应用内按需下载，不包含在安装包中。跨平台界面行为和实际音频输出仍建议在目标设备上确认。

Kokoro and ZipVoice models are downloaded on demand in the app and are not included in the installers. Cross-platform UI behavior and real audio output should still be checked on the target system.
