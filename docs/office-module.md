# 办公室模块

- **目标**：侧栏办公室以工具员工、办公桌与电脑展示真实任务状态。
- **范围**：只读快照类型、桌面控制 API/门面、原生渲染层 `office.ts` / `office.css`、本地插画与图标资源及构建拷贝。保留原生 TypeScript/CSS，不增加运行时依赖。
- **工位插画**：内置图像生成工具生成的透明背景精细 3D Q 版插画。四组人物与饰物采用正常坐姿、双脚落地，不交叉腿；通过工具 ID 稳定分配，刷新不换搭配。未安装工具使用空工位。桌面不放工牌，真实工具图标贴合插画原有的椅背小贴标，不叠加大底板，在 280px 工位上约 11px。当前选择的五张 WebP 保留透明通道，合计约 1.19 MiB。
- **图标**：内置工具使用真实品牌资源，Claude Code 使用基于官网标志轮廓重制的橙底白芯 SVG，规范画布与居中留白，其余来自官网或官方发布页；优先使用 API 已提供的真实图标。未知工具没有伪造图标，只显示工具名。原始来源、文件名与生成提示词见 [素材说明](../apps/desktop/src/renderer/assets/office/README.md)。
- **布局**：工位最大宽度为 280px，网格横向间距 28px、行间距 8px；消息预留高度 96px，单个工具筛选也不放大。饰物按使用区域安排，键盘、鼠标活动区优先留空，物品周围和桌沿保留可见空隙。CodeX CLI / Cline 的沙漏与本子分离；CodeBuddy 的记事本按员工视角竖向书写；水杯改为低矮杯型并移到桌内。Cursor 耳机与保温杯换位，杯高略降；无线充在显示器下方、支架右侧，供电线连续接入，屏幕动态内容仅在裁剪区域内显示。
- **消息**：仅工作中与待确认消息默认常显。空闲、完成、异常、未接入等信息仅悬浮或键盘聚焦显示；数据同步失败时停止自动消息与动效，并在悬浮消息中注明上次记录。工位下方不再固定显示状态、标题或任务列表。
- **交互**：点击工位固定展开 NPC 样式任务浮窗，支持任务分组、时间线与工具筛选看板。消息气泡和详情浮窗均有关闭按钮，详情也支持 Escape 与点击外部收起；关闭按任务身份和状态记录，不因数据刷新、标题或进度更新时间变化重弹，新任务/状态变化可以重新提示；旧消息仍可悬浮查看。键盘聚焦与触屏点击可替代悬浮。浮窗按可见内容区域定位与限高，滚动和窗口尺寸变化时重新定位。既有搜索、筛选和焦点/草稿保护继续复用。
- **动效**：工作中屏幕光标与代码柔和闪动，待确认状态灯提示；支持暂停和系统减少动态效果。不通过移动整张位图伪装人物打字或挥手。
- **状态语义**：安装状态与任务状态分开；忽略、暂停采集和仅检测安装不等于正在工作。历史快照不注入工作流或活跃计数，保留的异常和结束任务经浮窗查看。页面只读，不控制真实工具、不触发 TTS。
- **数据**：`GET /api/v1/office` 返回各工具全部可见会话的完整状态计数，每组最多四条任务预览；活跃、等待和异常不被结束任务挤掉。更多任务在看板查看。本轮不改变数据接口或状态机。
- **资源**：`assets/office/` 经 `copy-assets.mjs` 复制进 `dist/renderer/assets/office/`，安装后离线可用；图像生成、来源查询和图标下载仅发生于开发阶段。
- **验证边界**：渲染层编译、相关 ESLint 与差异检查；合成工位的静态插画叠加检查不等于真实 Electron 窗口、悬浮交互或安装包验收。此次未运行或增加自动测试，未启动用户真实数据实例。
