# 二次维护修复

- **目标**：修复本轮审查的五项问题，并建立本地 Git 基线。
- **范围**：桌面主进程的语音生命周期与设置文件、渲染层的刷新和看板分页、对应回归用例与说明。
- **对应决策**：延续 ADR-11 原生渲染层、ADR-18 分列分页、ADR-20 语音后端边界；没有新增运行时依赖。
- **成功标准**：修改播报范围或内容后不播放旧队列；看板刷新保留超过 100 条的加载深度且清理失效记录；高频事件不再反复全量请求设置等资源；设置文件和备份使用私有权限；播报范围无重复选项，云后端不提供无效语速调节。
- **实现**：后台按事件使相关缓存失效，带版本记录的请求不会吞掉请求期间的新事件；后台刷新串行并按请求数量延长间隔，主动刷新保持即时。看板从第一页和新游标重新读取，各列沿用其已加载数量，失败时保留旧数据，路由/筛选变化时拒收过期结果。
- **验证**：执行 `sh scripts/l1-verify.sh`，覆盖构建、类型检查、全部单测/集成测试、lint。新增用例仅使用合成任务、假语音后端与临时目录，不读取私人会话、不调用云 TTS。
- **结果**：新增 13 项回归用例，最终 51 个测试文件、737 项测试通过；typecheck（含构建）、test、lint 均退出 `0`。覆盖加载更多与后台刷新并发、过期分页、刷新期间的新事件以及失败重试。
- **未覆盖的验收**：真实窗口交互、实际音频及安装包运行。
