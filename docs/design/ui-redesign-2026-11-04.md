# 界面重构规格 · 2026-11-04

本次主题为「Apple 风本机仪表」：中性灰底、白色卡片、系统蓝主色，圆角柔和，不用绿色。仅重排渲染层视觉与文案层级，不改变路由、操作、数据字段或本地优先行为。

## 1. 设计计划

### 色彩

| 名称     | 浅色                  | 深色      | 用途                                 |
| -------- | --------------------- | --------- | ------------------------------------ |
| 画布     | `#f5f5f7`             | `#000000` | 应用背景（侧栏、页头、内容同一表面） |
| 卡片     | `#ffffff`             | `#1c1c1e` | 面板、任务卡、弹窗                   |
| 凹面     | `#ececf0`             | `#2c2c2e` | 看板列、输入槽、空态                 |
| 主文字   | `#1d1d1f`             | `#f5f5f7` | 标题与正文                           |
| 辅助文字 | `#6e6e73`             | `#98989d` | 说明、时间戳                         |
| 系统蓝   | `#0a84ff`             | `#0a84ff` | 主操作、当前分区、进行中、连接       |
| 待办琥珀 | `#a05a00` / `#e08600` | `#ffb340` | 待人工介入                           |
| 完成绿   | `#248a3d`             | `#30d158` | 仅用于「已完成」语义点               |
| 故障红   | `#d70015`             | `#ff453a` | 失败与超时                           |

状态色仅用于状态文字、徽标、微型圆点与刻度，不铺大面积渐变，也不作为主色。浅色/深色共用同一套语义与对比度目标：正文与辅助文字分别不低于 7:1 与 4.5:1。

### 字体与字阶

- 优先使用系统字体（macOS 上为 SF Pro / PingFang SC），Windows/Linux 回退到已打包的 Inter 与系统中文；数字用本地 JetBrains Mono，离线可用。
- 字阶：`11 / 12 / 13 / 14 / 16 / 20 / 28 / 44px`。11px 仅用于仪表刻度、时间戳与计数；12px 用于标签和辅助信息；13px 为控件与次级文字；14px 为正文；16px 为面板标题；20px 为页面标题；28px 为次要读数；44px 为总览主读数。
- 字重只取 400 / 500 / 650：正文 400，按钮与列表标题 500，页面/面板标题 650。数字用等宽、tabular-nums、轻微负字距；中文标题不用全大写和夸张字距。
- 行高：正文 1.6，紧凑列表 1.45，标题 1.25，读数 1。正文行长控制在约 70–80 个字符以内。

### 布局与对齐

```text
┌────────────┬──────────────────────────────────────────────────────┐
│ 品牌 / 型号 │ 页面标题 · 一句用途              刷新   扫描工具      │
│            ├──────────────────────────────────────────────────────┤
│ 监控       │ ┌──────── 主读数 ────────┬── 三项刻度 ─────────────┐ │
│  总览      │ │ 44px 等你拍板           │ 进行中 / 完成 / 需关注 │ │
│  办公室    │ └────────────────────────┴─────────────────────────┘ │
│  看板      │ ┌──────── 需要你处理 ────────┬── 进行中 / 工具清单 ┐ │
│  通知      │ │ 左对齐列表                │ 上下文列表            │ │
│ 接入       │ └───────────────────────────┴──────────────────────┘ │
│ 配置       │                                                      │
│            │ 所有页面共用一条 16px / 24px / 32px 的内容栅格        │
│ 引擎状态   │                                                      │
│ 静音       │ 左对齐阅读，数字右对齐；控件贴齐 36px 基线            │
└────────────┴──────────────────────────────────────────────────────┘
```

- 侧栏固定 224px（中屏 194px、窄屏 160px）；内容区最大宽度 1120px（超宽屏 1180px），居中，避免超宽屏行长失控。
- 间距只取 `4 / 8 / 12 / 16 / 24 / 32 / 48px`；控件高 36px，小控件 30px；同组标题到内容 16px，面板间距 16px，页面安全边距 32px（窄屏 16px）。
- 圆角：面板/卡片 14px，按钮与输入框 10px，小控件 8px；按钮改为全圆角胶囊。去掉 3px 左侧色条与列顶色条，状态只由圆点、徽标和浅色底承载。
- 导航当前项使用浅蓝底 + 蓝色文字 + 圆角短刻度；页头、侧栏与内容使用同一底色 `--bg`，白色卡片浮于其上。
- 设置页沿用「标签在左、控件在右」两栏；760–950px 改单栏，控件宽度跟随列宽。看板四列在 1100px 以下变两列，760px 以下变一列。通知在窄屏把操作下移。办公室工位维持 220px 最小列宽，不放大插画。

### 原则

1. 以「刻度、对齐、留白」取代发光、点阵与装饰性渐变。
2. 一屏只有一个大数字；其他信息用规则化的列表和刻度承载。
3. 色彩只编码状态，不制造装饰；同一状态在总览、看板、通知、时间线保持一致。
4. 所有文字与控件沿用既有 DOM 和数据属性，保证刷新、草稿保存、键盘焦点与区域差分重绘行为不变。
5. 动效只响应操作与真实状态变化；遵循系统「减少动态效果」。

## 3. 面向需求的复核

- 「简洁、大气」：单一表面 + 白色卡片，减少装饰层数与字重档位，内容列统一最大宽度。
- 「Apple 风与质感」：系统蓝、中性灰阶、SF 优先字体、胶囊按钮与柔和圆角；不用绿色作主色。
- 「细节精细」：统一 14/10/8px 圆角、1px 边线、36px 控件高度、8px 网格、tabular-nums 与焦点可见性。
- 「文案通俗」：界面文案改为直白短句，去掉「适配器 / 会话来源 / 状态迁移」等实现术语；按钮使用动词短语（「我已处理」「再试一次」「去申请 Key」）。
- 「功能不变」：不新增/删除交互控件；不修改路由、请求、事件绑定、状态数据的来源。
- 「响应式与一致性」：保留既有 1100 / 950 / 760px 断点并重新校验；深浅主题使用同一套布局与语义色。

## 4. 实施与验证边界

- 实施文件：`apps/desktop/src/renderer/styles.css`、`office.css`、`index.html`、`views.ts`、`app.ts`、`office.ts`、`ui.ts`；主进程仅同步窗口底色 `window.ts`。
- 验证：渲染层 `tsc --noEmit`、全部 vitest、ESLint、Prettier，以及浏览器深/浅色实渲染；桌面应用真实 Electron 窗口与用户数据交互不在本次改动范围。
