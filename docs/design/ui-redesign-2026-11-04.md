# 界面重构规格 · 2026-11-04

当前方向为「轻量任务工作台」：冷中性色承载内容，靛蓝只强调主要操作与当前状态；侧栏单独分层，表单依靠留白分组，减少装饰线和重复阴影。沿用 AgentCue 的导航、任务信息与办公室插画；不改变路由、数据字段或本地优先行为。

## 1. 设计计划

### 色彩

| 名称     | 浅色                  | 深色      | 用途                                 |
| -------- | --------------------- | --------- | ------------------------------------ |
| 画布     | `#f5f7fa`             | `#11151b` | 内容区与页头背景                     |
| 侧栏     | `#eef1f6`             | `#0d1117` | 导航背景，与内容保持轻微层次         |
| 卡片     | `#ffffff`             | `#181d25` | 面板、任务卡、弹窗                   |
| 次表面   | `#f1f4f8`             | `#202631` | 看板列、输入槽、空态                 |
| 主文字   | `#1b2230`             | `#edf1f7` | 标题与正文                           |
| 辅助文字 | `#626f83`             | `#a0aaba` | 说明、时间戳                         |
| 靛蓝     | `#405bd2`             | `#536bd0` | 主操作、当前选择与进度               |
| 待办琥珀 | `#85520d` / `#d78917` | `#f1b95b` | 待人工介入                           |
| 完成绿   | `#1e7542`             | `#64c98a` | 仅用于「已完成」语义点               |
| 故障红   | `#c63842`             | `#ff7773` | 失败与超时                           |

状态色仅用于状态文字、徽标、微型圆点与刻度，不铺大面积渐变，也不作为主色。浅色/深色共用同一套语义与对比度目标：正文与辅助文字分别不低于 7:1 与 4.5:1。

### 字体与字阶

- 优先使用系统字体（macOS 上为 SF Pro / PingFang SC），Windows/Linux 回退到已打包的 Inter 与系统中文；数字用本地 JetBrains Mono，离线可用。
- 字阶：`11 / 12 / 13 / 14 / 16 / 20 / 28px`。11px 仅用于时间戳与计数；12px 用于标签和辅助信息；13px 为控件与次级文字；14px 为正文；16px 为面板标题；20px 为页面标题；28px 为总览刻度。
- 字重只取 400 / 500 / 650：正文 400，按钮与列表标题 500，页面/面板标题 650。数字用等宽、tabular-nums、轻微负字距；中文标题不用全大写和夸张字距。
- 行高：正文 1.6，紧凑列表 1.45，标题 1.25，读数 1。正文行长控制在约 70–80 个字符以内。

### 布局与对齐

```text
┌────────────┬──────────────────────────────────────────────────────┐
│ 品牌 / 型号 │ 页面标题 · 一句用途              刷新   扫描工具      │
│            ├──────────────────────────────────────────────────────┤
│ 监控       │ ┌──────── 主读数 ────────┬── 三项刻度 ─────────────┐ │
│  总览      │ │ 任务状态与接入情况       │ 待处理 / 进行中 / 完成 │ │
│  办公室    │ └────────────────────────┴─────────────────────────┘ │
│  看板      │ ┌──────── 需要你处理 ────────┬── 进行中 / 工具清单 ┐ │
│  通知      │ │ 左对齐列表                │ 上下文列表            │ │
│ 接入       │ └───────────────────────────┴──────────────────────┘ │
│ 配置       │                                                      │
│            │ 所有页面共用一条 16px / 24px / 32px 的内容栅格        │
│ 引擎状态   │                                                      │
│ 音量       │ 左对齐阅读，数字右对齐；控件贴齐 38px 基线            │
└────────────┴──────────────────────────────────────────────────────┘
```

- 侧栏固定 232px（中屏 194px、窄屏 160px）；内容区最大宽度 1120px（超宽屏 1180px），居中，避免超宽屏行长失控。
- 间距只取 `4 / 8 / 12 / 16 / 24 / 32 / 48px`；控件高 38px，小控件 30px；同组标题到内容 16px，面板间距 16px，页面安全边距 36px（窄屏 20px）。
- 圆角：面板 16px、行内卡片 12px、输入框和按钮 9px、小控件 8px。主按钮用紧凑实底样式，悬停不发光；任务状态仍由圆点、徽标和浅色底承载。
- 导航当前项使用浅靛蓝底与蓝紫文字，不加侧边刻度；页头与内容共享画布，侧栏使用独立中性表面。
- 设置页沿用「标签在左、控件在右」两栏；描述列宽 300–420px，以间距组织字段，避免每行一条分隔线。设置分成四个可键盘切换的标签页。看板四列在 1100px 以下变两列，760px 以下变一列。办公室工位维持 220px 最小列宽，不放大插画。

### 原则

1. 以「刻度、对齐、留白」取代发光、点阵与装饰性渐变。
2. 用一条标题表达当前关注点；计数与任务列表保持紧凑、可扫读。
3. 色彩只编码状态，不制造装饰；同一状态在总览、看板、通知、时间线保持一致。
4. 刷新、草稿、焦点和差分重绘保持稳定；设置分区改为四个可键盘切换的互斥面板，隐藏面板时保留待保存值。
5. 动效只响应操作与真实状态变化；遵循系统「减少动态效果」。

## 3. 面向需求的复核

- 「简洁、大气」：单一表面 + 白色卡片，减少装饰层数与字重档位，内容列统一最大宽度。
- 「清爽现代」：低彩冷中性色、克制靛蓝、系统优先字体、紧凑按钮和清晰间距；状态色只表达状态。
- 「细节精细」：统一 16/12/9/8px 圆角、1px 边线、38px 控件高度、8px 网格、tabular-nums 与焦点可见性。
- 「文案通俗」：界面文案改为直白短句，去掉「适配器 / 会话来源 / 状态迁移」等实现术语；记录操作明确说明只更新 AgentCue 状态，使用「标记已响应」「标记已重试」等准确动词。
- 「交互边界」：不改路由、请求或状态来源；设置分区只切换显示，保持原来的保存与事件处理。
- 「响应式与一致性」：保留既有 1100 / 950 / 760px 断点并重新校验；深浅主题使用同一套布局与语义色。
