# 本机管理与接入验收

以下功能位于 Rust / Tauri 安装版；旧 Electron 开发入口不提供原生系统操作。

## 建立连接

首次进入总览可选择一个工具，进入「播报接入」复制对应 Hooks 或 MCP 配置，保留原工具已有配置。可跳过，之后在「设置 → 应用与数据」重新打开引导。

点击开始验证后，在原工具发一个新任务。诊断分别显示新收到的开始、待确认、完成时间；三类汇总可能来自不同任务。完整验收还需对照同一个任务的时间线，确认开始一次、需要用户时一次、完成一次，再重启 AgentCue，确认没有重播。诊断收到事件不等于实际扬声器出声，仍需检查静音、时段、规则和试听。

Windows：Cursor 使用 PowerShell；Cline 需要支持 `.ps1` Hooks 的版本，脚本按 UTF-8 BOM 保存；Claude Code 需要支持 `shell=bash` 的版本，CodeBuddy 使用 Git for Windows。配置生成不等于所有工具版本都可执行，需在本机按步骤验证。

CodeX 的来源能力单独声明。JSONL 中没有可靠的人类待审批信号；自动审核之前触发的 PermissionRequest 也不能区分是否真的交给用户处理，因此不将其直接当作待确认。

## 应用与数据

- 登录启动只注册当前用户；隐藏启动后通过托盘或菜单栏打开。
- 默认关窗继续监控，可改为关窗退出。
- 数据面板展示数据库、模型和备份占用，可打开本机数据目录。
- 创建备份后，从列表选取并确认恢复。下次启动执行，之前可取消；安排时和实际恢复前都会创建安全备份。损坏备份会显示失败结果并保留原数据。
- 备份含任务数据库和主设置，不含 API Key、模型、参考录音、独立读音词典与登录启动配置。恢复保留当前云语音配置。没有自动上传或跨设备同步。
- 保留天数 0 表示永久；7–3650 天可以预览或启用每日清理。只清理过期完成、取消、归档任务及关联事件/通知，保留未解决任务和来源检查点。删除后需从备份恢复；SQLite 可复用释放页，文件体积不一定立即缩小。
- 脱敏报告先预览再导出，仅含版本、平台、计数、工具状态和事件类型时间；不含任务标题、正文、路径或凭据。
- 手动检查更新仅访问官方 GitHub 最新正式版元数据；点击链接后自行下载安装，不自动替换应用。

## 语音与模型

语音页显示当前播放状态，可停止当前及排队播报，失败后可手动重试。自定义词典一行一项 `原词 = 读法`；只改变发音，不改任务标题。云服务的提示与播报一起发送，不能保证模型严格遵循每项读音。

模型卡展示声明来源、目录与占用；可验证本机 SHA-256、删除、重新下载或从本机已解压目录导入。首次校验只建立本机基线，不能证明下载真实性。导入需保持官方目录结构；缺少必需文件、符号链接和过大目录会明确失败。下载/导入/删除互斥，避免使用半套模型。重新下载或删除将停止当前播放。

## 看板与办公室

看板支持日期、工具、关键词和时间排序；计数与分页按同一筛选查询。批量归档只针对当前已加载的已结束记录，最多 100 条，操作前确认。任务操作只改变 AgentCue 记录。

办公室记住搜索、筛选、动效及待确认优先偏好，遵循系统减少动效设置。可用键盘聚焦工位查看信息。任务详情只有取得有效工具或项目路径时才显示打开按钮，不会把未知路径猜成命令执行。
