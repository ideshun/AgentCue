# ADR-21：Rust 核心与 Tauri 2 渐进迁移

- 状态：已完成并于 v1.0.0 正式发布。
- v0.2.0 是最后一个 Electron 稳定版；v1.x 以 Rust + Tauri 2 为正式桌面宿主。
- 正式发布版本：Rust workspace 与 Tauri 配置共同使用 `1.0.0`；预览版本保留在历史标签 `v1.0.0-alpha.1`。

## 决策与原因

当前应用安装体积主要由 Electron 运行环境构成，体积依据见[发版手册](../releasing.md)。使用 Rust 接管后台核心、Tauri 2 使用系统 WebView，复用原生 TS/CSS 页面、办公室插画及交互，不引入新的前端框架。

迁移首先保持任务与通知语义，再替换宿主。不得仅为了得到一个可打开的 Tauri 窗口而静默丢弃现有功能，或长期附带 Electron / Node 作为生产后台。

## 第一阶段：状态契约

`crates/agentcue-core` 提供七态任务状态机、十二种事件类型、非法迁移错误和内存状态恢复，不依赖 UI 或第三方运行库。

迁移期间 `packages/schema/src/{state,event}.ts` 与 `packages/core/src/statemachine/transition-table.ts` 仍是已发布行为的依据。`scripts/export-rust-contract.mjs` 导出所有状态／事件组合；Vitest 检查夹具与 TS 源码一致，Rust 对同一夹具穷举校验，防止两套实现漂移。待现有引擎完全退出生产路径后，再单独决定统一契约的生成方式。

状态契约阶段曾以隔离数据库和合成数据验证。1.0 正式宿主沿用历史数据目录，并在连接现有用户数据前执行数据库备份与迁移保护。

## 已交付实现

`crates/agentcue-store` 使用 rusqlite 0.37（MIT）及 bundled SQLite（SQLite 本身公有领域），由 Cargo.lock 固定实际版本。显式文件连接提供升级前在线备份、权限收紧和 WAL；来源事件、收据、标题、可见性与检查点同事务提交，读取位置使用比较后写入，允许真实截断并拒绝过期批次。当前只使用隔离的合成数据，尚未接通安装版数据。

`crates/agentcue-adapters` 保留格式专属逻辑：用户标题、路径引用、JSONL 轮次、内部来源过滤、历史索引及四种原生 Hooks。`serde_json` 保留字段顺序，并使用 `ryu-js` 格式化数字，确保事件摘要与 JavaScript 的序列化一致；导出夹具同时覆盖稳定 ID 与分批上下文。

`crates/agentcue-runtime` 使用 Tokio 承载文件 I/O、进程和定时任务，Axum 提供仅监听回环地址的控制 API，reqwest 提供本机桥接及用户显式请求的外部 MCP HTTP。新增依赖的目的分别是原生异步运行时、本机 HTTP、JSON 契约、时间解析、摘要/随机身份、已声明目录的文件名匹配和常量时间鉴权；不引入前端框架或生产 Node 后台。外部 MCP 为有界短期验证：初始化、通知、分页、响应 ID 校验、超时、stdio 进程组清理以及 HTTP 会话删除。Unix 仅用 libc 发送信号给自己创建的验证进程组。

本地 TTS 使用 Sherpa 官方维护的 `sherpa-onnx` Rust crate 2.0.1（Apache-2.0），作为独立 `agentcue-tts` 推理工作进程，桌面后台不加载 Node 原生插件。模型与词典沿用现有目录，运行库在构建期取得，模型仍只能由用户显式下载。工作进程只做推理，不联网、不读数据库、不负责播放；取消和超时由父进程终止工作进程，避免原生推理故障拖住桌面或遗留无法取消的后台线程。每次只保留一种模型实例，空闲释放策略随语音生命周期接入。Rust workspace 声明 1.89，使用标准库文件锁防止同一数据目录的并发写入。

Tauri 宿主通过窄桥接复用既有页面，提供窗口、托盘、通知、试听、参考音频选择及设置草稿退出确认。回环 API 继续采用鉴权和一次性 SSE 票据；实际安装包同时携带桌面入口与推理工作进程。构建、升级及发布见[原生版交付手册](../native-preview.md)。

1. **存储和事件消费**：用合成数据库验证 SQLite 五次历史迁移、事务、外键、追加事件、稳定去重、乱序降级、可见性和重启恢复；状态与来源检查点同事务提交后，才产生通知与播报。
2. **采集与接入**：迁移 manifest、安装识别、增量读取、Hooks 和 MCP 桥接。覆盖追加、半行、截断、替换、超大记录、重启和忽略／隐私开关即时生效。
3. **语音与设置**：保持开始／待确认／完成提醒范围、只播一次、全局静音优先、音量和文件引用精简；保留原生、本地及显式启用的云 TTS。Rust 通过原生接口或现有推理库实现，模型继续由用户主动下载。
4. **Tauri 宿主**：复用当前页面与素材，以 Rust/Tauri 替换 Electron preload/IPC 和窗口、托盘、通知、文件对话框。保留设置草稿、键盘交互、关闭确认、主题与减少动态效果。
5. **1.0 验收和发布**：完成四个平台构建、自检与 SHA-256 发布流程。正式签名、公证和自动更新尚未配置；跨平台真实工具交互与音频设备需按目标环境继续人工验收。

## 必须保持的兼容边界

- 应用标识 `com.awm.app`、安装位置下的可执行入口、`--tool-hook` / `--mcp-stdio` 参数与 MCP Server 标识保持兼容；无法保持时提供明确迁移步骤，不追加重复配置。
- 历史数据目录继续使用 `AI Workflow Monitor`。数据库、设置、模型、参考音频和握手文件的布局在对应迁移验证完成前不得更换。
- 数据库升级前提供备份；拒绝写入比当前实现更新的数据库版本。不得同时启动两个写入引擎。
- 保留事件 ID、任务身份粒度、状态与错误码；先验证去重和重启恢复，再接通自动播报。
- 文件采集只读取声明来源；被忽略工具停止采集；关闭读取后停止对应心跳。API 继续限于本机并进行鉴权。
- 正式 1.0 必须保留本地优先、云语音显式开启、完整插画素材保留和当前功能边界。
