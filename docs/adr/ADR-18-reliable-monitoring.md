# ADR-18：可靠采集、只读历史与可验证的桌面接入

日期：2026-10-20。状态：已实施。

## 决策

- 安装识别与五秒任务采集分开。心跳只维护观测值，来源检查点按文件身份、字节位置、首部/边界指纹持久化。已完整读取的行、稳定事件身份、消费收据和检查点在同一事务提交；失败时回滚内存 actor，提交后才分发通知。
- 仅探测来源不读取会话占位路径。隐私开关和忽略清单在安装识别、采集、心跳及超时统一生效；撤销设置使在途批次失效。旧数据库忽略标记迁入设置后不再作为第二处真源。
- Cline 4.1.25 公开扩展代码展示旧 `state/taskHistory.json` 数组与新 `sessions/sessions.index.json` v1 对象。只读取 manifest 声明位置的索引字段，不读取对话、凭据或其引用路径；格式不匹配时降级。CodeBuddy 只验证扩展安装身份。历史快照不写入七态状态机，未知状态不假装已完成。
- 看板单独提供分组查询、全量计数和按更新时间/ID分页。UI 通过类型化补丁、编辑草稿和请求代数保留用户操作。状态快捷操作只记录 AWM 状态，不代操作被监控工具。
- 保留原生 TS/CSS 与 MCP 2025-06-18，无新增运行时依赖。桌面轻量入口先分发 `--mcp-stdio`，共用 CLI 协议实现，不启动窗口、单实例锁或数据库；构建复制桥接产物，由客户端使用绝对路径启动。
- 外部 MCP 是短期验证：初始化、枚举、清理；验证状态与连接状态分开。严格检查响应身份和形状，限制时间/缓冲，支持标准 HTTP JSON/SSE 响应。
- 全局静音优先于时段例外。语音关闭降级到通知，规则 mute 不发提醒。取消和重配等待旧播放结束，试听返回实际后端与诊断。Piper/云端缺少完整播放适配时不可用，不再将生成文件或 HTTP 成功视为声音已播放。
- macOS 默认英文音色可能对中文生成静音；中文文本选择已安装的中文音色，合成后验证 AIFF 中存在非零音频数据再交给系统播放，结束后清理临时文件。系统输出设备和硬件静音仍由操作系统控制。
- 系统原生引擎与音色分别展示。macOS 仅读取 `say -v ?` 的已安装列表，按语言分组选择；保存完整名称作为 voiceProfile，自动中文兼容带括号的婷婷名称。只修改规则动作时保留既有文案和优先级，空文案按事件生成短句，避免开始/完成误报为需要处理。
- 标题只从验证过的用户消息形状提取，剥离明确的控制上下文，保留合法用户 JSON 和代码；助手的 `last_agent_message` 不是任务标题。启动后可有界读取已声明来源首部，单独回填旧会话和检查点标题，不改状态/时间/消费位置，不发送提醒。缺标题的后续事件保留已有标题。
- Codex 公开协议为任务开始/完成提供 `turn_id`，因此按轮次生成独立任务身份，保留终态禁止直接回跳的状态机约束。检查点 v4 增加最小任务上下文，跨读取批次与重启恢复当前轮标题。旧文件级会话保留，不回放已消费事件。[协议源码](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)、[持久化策略](https://github.com/openai/codex/blob/main/codex-rs/rollout/src/policy.rs)。
- 按首条 `session_meta.payload.source` 的公开序列化结构分类：`internal` 的 guardian/memory_consolidation 与 `subagent` 的 review/compact/memory_consolidation 仅属于辅助流程；不依据正文中的 risk_level 等字段猜测来源。普通来源、未知来源和 thread_spawn 委派任务保留。排除标记跨批持久化，清除其检查点标题上下文；v5 仅隐藏已有辅助会话，不改旧任务元数据、状态或事件。隐藏记录不参与列表、计数、心跳和迁移播报。
- 只有精确覆盖当前消费位置的前缀才能重建任务上下文，未消费部分不能提供未来任务上下文；消费成功后同步缓存位置。来源标题可以单独修复，后续事件不会再用旧上下文覆盖已修正的标题。隐私/忽略变更在异步读取边界核对，撤销后不继续发起内容读取。
- 开始、待确认和完成出厂规则均播报；宿主以 rulesRevision 做一次性精确升级，保留自定义动作与文案。最终提醒补足工具显示名、任务标题和事件；无标题时与界面使用相同稳定短编号。冷却期接受新任务并排队，通知及时保留；重复事件仍去重，免打扰继续生效。
- 自动提醒使用标准事件 ID 去重，已接受的身份不因原三十秒窗口到期、播放结束或设置重配而释放。历史采集与提醒分开：监控构造、重新配置时建立时间基线，旧事件继续落库和刷新，基线之后的真实事件才进入提醒；跨读取批次沿用该基线，合成的补全起始事件不提醒。显式试听仍由每次用户点击触发。
- 测试启动器检查 SQLite 运行时 ABI，不匹配时选择项目 Electron-as-node，不通过反复 rebuild 破坏桌面与测试环境；L1 汇总失败退出码。

## 兼容与验证

来源检查点、消费收据及 MCP 验证字段通过数据库 v3 迁移新增；v4 为来源检查点新增可空任务上下文；v5 为会话增加默认可见标记。旧会话接口、任务状态及 MCP 六工具名不变。
回归覆盖文件追加/半行/截断/替换/重启、事务失败、隐私撤销、索引最小字段、按列分页、设置草稿、语音取消与静音、MCP 异常输出及安装资源入口。

## 2026-10-21：官方 Hooks 与播报范围

Cursor、Cline、CodeBuddy 的实时开始/结束通过官方 Hooks 送入独立的本机鉴权接口。客户端保存配置，应用不写客户端目录；独立 `--tool-hook` 入口在窗口、单实例锁与 SQLite 导入前分派。输入有上限和时限，失败放行，只转发最小任务身份、时间与短标题。沿用来源收据、状态事件及事务后通知，不建立伪文件检查点，也不放宽 MCP 状态操作白名单。

能验证原生轮次时使用原生身份；无轮次时按来源和发生时间关联。缺开始、恢复、关闭遗留轮次都静默补全。客户端尚无可靠待确认信号时，不将工具执行前事件映射为等待确认。接入状态以最近真实任务事件为证据。

自动语音严格限制开始、待确认、完成三个阶段；其他事件只通知或静音。macOS 列表与实际播放仅使用 Sinji（善怡）粤语，缺少时明确失败。旧不可用音色安全回退，界面提供显式保存自动选项。规则修订标记升为 2，只精确降级内置失败/超时规则，用户静音保持不变。详见[接入文档](../integrations/task-hooks.md)。

## 2026-10-22：Claude Code 官方 Hooks 接入

Claude Code 加入任务播报接入，使用用户级 `~/.claude/settings.json` 的 `UserPromptSubmit`、`Stop` 和带 `permission_prompt` matcher 的 `Notification`。会话身份不再单独散列：由 `transcript_path` 的父目录名与去扩展名文件名拼成 `claude-code:{project}:{sessionKey}`，与 JSONL 文件适配器使用同一身份，Hook 事件和文件采集落在同一任务记录；仅路径缺失时回退到 `claude-code:hooks:{sha256(session_id)}`。事件 ID 只含派生会话键、`prompt_id`（无则用接收时间）和阶段，不含正文、路径、cwd 或用户身份。`Notification` 的 `permission_prompt` 视为等待确认，批准本身只通过其后的开始/完成事件间接观察。Claude Code 会把 `UserPromptSubmit` 的纯文本 stdout 注入 Agent 上下文，故桥接在所有阶段只输出 `{}`，加载失败也不例外。凭据、transcript 内容与出网边界不变。
