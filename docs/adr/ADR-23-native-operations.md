# ADR-23：原生应用的本机维护与显式网络操作

状态：已实施，正式签名和跨平台人工验收依赖外部环境。

## 决策

复用现有 Rust runtime、SQLite 和 Tauri 命令，不新增运行时依赖。

- 备份使用 SQLite 在线备份，包含 WAL 已提交数据和脱敏主设置。恢复只从本机受管 UUID 备份目录读取，检查格式、数据库版本、完整性和表结构；下次启动持锁执行，先备份最新状态，失败则回滚并记录结果，回滚失败停止启动。云语音配置保留当前值，不用旧备份中的 Key 或 endpoint 替换。
- 正常事件处理保持追加；用户明确确认的保留期限清理是例外，事务删除过期 completed/cancelled/idle 记录与关联事件和通知。进行中、待确认、失败、超时及采集检查点不删除，避免重放。默认永久保留。
- 诊断报告只输出白名单字段，先预览再导出，不输出任务内容、路径、命令和凭据。
- 系统登录启动按平台注册用户级项，隔离预览禁止修改。窗口关闭默认隐藏，允许用户改为退出。
- 更新仅由用户点击触发，请求固定官方 GitHub Release 地址，限制超时、响应体大小和下载来源；不自动下载或安装。
- 模型只从声明的官方地址下载，或导入用户选择的本机已解压目录。操作互斥，拒绝符号链接，暂存后替换；本机 SHA-256 基线用于发现改动，不宣称发布者认证。
- 云语音的自定义读音作为提示发送，系统/本地后端使用边界匹配替换；不改任务标题。停止播放取消当前及队列，重试只由用户显式触发。
- CI 签名凭据仅从仓库 Secrets 获取，导入一次性 runner 后清理；没有证书时不宣称正式签名或公证。发布版本不可覆盖。

## 证据位置

`crates/agentcue-runtime/src/maintenance.rs`、`voice/{models,service,backends}.rs`、`apps/tauri/src/{features,desktop,services}.rs`、`scripts/native-signing.mjs`、`.github/workflows/native-release.yml`。

## 边界

备份不含模型、参考录音、独立词典及系统注册项。更新检查不替代包校验或人工安装。实际证书、不同系统的窗口/音频行为及各工具新版 Hooks 需要目标环境验收。CodeX 自动审核前的 PermissionRequest 不等同于用户需要确认，不据此制造待审批提醒。
