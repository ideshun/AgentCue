# Rust SQLite 迁移层

使用 rusqlite 的 bundled SQLite，避免依赖用户机器上的 SQLite 安装。仅接收显式提供的连接，不自动打开应用数据目录。

目前实现五版历史 schema 的原子升级、重复调用、未知新版本拒绝、显式文件打开、升级前在线备份及 WAL。SQL 从现有 TS 存储导出，由 Vitest 对照源码检查，Rust 测试使用内存数据库验证各历史版本的升级、记录保留、外键及失败回滚。

```sh
pnpm rust:contract
pnpm rust:verify
```

首次运行需下载 Cargo.lock 固定的依赖。`open` 负责文件升级前在线备份和连接配置；`engine` 提供事件、收据、来源检查点和元数据的联合事务。来源提交比较先前检查点，防止旧批次覆盖新进度，同时允许已验证的截断重置。事务返回后才可派发播报或通知。当前模块尚未连接安装版应用。
