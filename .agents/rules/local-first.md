# 本地优先与隐私

## 适用范围

改扫描、控制 API、TTS、设置开关、审计日志、或任何可能出网 / 读用户文件的代码时。

## 应保持行为

- 运行期默认零出网。云 TTS 仅为未来插件且须用户显式开启；当前不要实现偷偷出网的后端。
- 唯一例外（ADR-19）：本地 Kokoro 语音模型下载，必须由用户在设置页显式点击触发，界面明确说明大小与来源；失败不自动重试、不自动换源；模型只落本机数据目录。
- 扫描只读取适配器声明路径，不递归家目录或磁盘。忽略清单经设置 / API 生效后，重扫不得再出现该项。
- 控制 API 仅 `127.0.0.1`。除 OPTIONS 与 SSE 外要求 `Authorization: Bearer <token>`（常量时间比较）。限流 120 次/分钟，Hook 投递与查询/控制分桶互不挤占。SSE 经 `POST /api/v1/stream-ticket` 换一次性票据接入，token 不出现在 URL。调用记 `audit_log`；可能含会话内容的字段不入审计。
- token 与端口写在 userData `runtime.json`（权限 0600）。不要把 token 打进日志或提交到仓库。
- 不读取 `.env*`、凭证、钥匙串、私人聊天记录、`memory/`、生产用户数据库，除非用户在本任务中明确给出且为实现所必需。
- 被监控工具：只读会话与配置以识别状态。不向其写入指令。状态回写只走 MCP `update_task_state` 白名单事件。

## 待确认

- 抓包验收（FR-05）尚无自动化脚本。
- 审计日志关闭开关若改行为，需同时核对设置 schema 与 UI 文案。

## 验证边界

API 鉴权 / 限流用现有单测或 curl 打本机端口。不要为验证去扫描用户真实会话目录以外的路径。不提交 `runtime.json`。
